. 基础文本与段落样式架构Ctrl + Alt + 0 (Mac: Cmd + Opt + 0) ➡️ 正文（Paragraph / Text）Ctrl + Alt + 1 (Mac: Cmd + Opt + 1) ➡️ 一级标题（Heading 1 / H1）Ctrl + Alt + 2 (Mac: Cmd + Opt + 2) ➡️ 二级标题（Heading 2 / H2）Ctrl + Alt + 3 (Mac: Cmd + Opt + 3) ➡️ 三级标题（Heading 3 / H3）Ctrl + Alt + 4 (Mac: Cmd + Opt + 4) ➡️ 四级标题（Heading 4 / H4）2. 高级块级元素（数字顺延区）由于 4 级以上的标题在现代云端文档中极少被使用，黄金左手区的数字 5 和 6 被顺延留给了最常用的排版块：Ctrl + Alt + 5 (Mac: Cmd + Opt + 5) ➡️ 引用块（Blockquote）Ctrl + Alt + 6 (Mac: Cmd + Opt + 6) ➡️ 代码块（Code Block）备选语义化方案：也有部分框架采用字母组合，如 Ctrl + Shift + B（Blockquote）或 Ctrl + Shift + C（Code Block）。3. 列表与复合结构（Shift 组合区）列表作为需要频繁缩进的嵌套结构，业界习惯使用 Shift 作为辅助修饰键：Ctrl + Shift + 8 (Mac: Cmd + Shift + 8) ➡️ 无序列表（Bullet List）Ctrl + Shift + 9 (Mac: Cmd + Shift + 9) ➡️ 有序列表（Ordered List）Ctrl + Shift + 7 (Mac: Cmd + Shift + 7) ➡️ 待办事项/任务列表（Todo List）提示：在键盘上，8 键对应的上档符号是 *，9 键靠近 (，这延续了 Markdown 语法中用 * 代表无序列表的直觉。4. 高级组件区Ctrl + Alt + T (Mac: Cmd + Opt + T) ➡️ 表格（Table）（取自 Table 首字母）Ctrl + Alt + H (Mac: Cmd + Opt + H) ➡️ 高亮块（Callout / Highlight）
